Almost ready — this copy isn't connected to a database yet.

  1. Go to console.firebase.google.com and create a project.
  2. Build → Authentication → Get started, then enable Email/Password.
  3. Build → Realtime Database → Create database (locked mode is fine). Open its Rules tab and paste in the contents of database.rules.json, then Publish.
  4. Project settings → Your apps → Web (</>), register the app, and copy the firebaseConfig values.
  5. Open this file in a text editor, paste those values into the FIREBASE_CONFIG block near the top of the script, and upload it to an https site (GitHub Pages works — phones only share GPS with https pages).

Want to check the scavenger-hunt pins first? Add ?setup to the page address — that mode works without Firebase.
