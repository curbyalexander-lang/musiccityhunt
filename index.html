  1. Go to console.firebase.google.com and create a project.
  2. Build → Authentication → Get started, then turn on Email/Password.
  3. Build → Realtime Database → Create database. Open its Rules tab, paste in database.rules.json, and click Publish.
  4. Project settings → Your apps → Web (</>). Register the app and copy the firebaseConfig values into the FIREBASE_CONFIG block in this file.
  5. Upload the file to an https site such as GitHub Pages. Phones only share GPS with https pages.

To look around without Firebase, add ?demo to the page address, or open the file straight from your computer.
